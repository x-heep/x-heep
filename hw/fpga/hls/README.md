# HLS accelerator example: streaming dot product

A small dot-product accelerator, written in C/C++ and generated with any of
three HLS tools, wired into X-HEEP as a memory-mapped accelerator (simulation
with Verilator, and the `pynq-z2` FPGA). The whole thing is opt-in: pass
`use_hls_example` plus **one** tool flag to FuseSoC.

| HLS tool | Flags | Directory | Host needs |
|----------|-------|-----------|------------|
| Vitis HLS | `--flag use_hls_example --flag use_vitis_hls` | [`vitis/dot_product`](vitis/dot_product) | Vivado + Vitis HLS |
| Bambu HLS (open source) | `--flag use_hls_example --flag use_bambu_hls` | [`bambu/dot_product`](bambu/dot_product) | Docker |
| Dynamatic (open source) | `--flag use_hls_example --flag use_dynamatic_hls` | [`dynamatic/dot_product`](dynamatic/dot_product) | Docker |

```sh
make mcu-gen
make verilator-build FUSESOC_FLAGS="--flag use_hls_example --flag use_dynamatic_hls"
make app PROJECT=example_dot_product_hls TARGET=sim
make verilator-run FUSESOC_FLAGS="--flag use_hls_example --flag use_dynamatic_hls"
```

`common/dot_product` holds what does not depend on the tool (header, C++
testbench, the OBI wrapper with its AXI<->OBI bridges, the `epfl:ip:dot_product`
FuseSoC core that selects the tool, and the regtool CTRL register file used by
the tools that cannot generate one); each tool directory holds its kernel, its
generation scripts and a small `dot_product_hls_adapter` module. The software
(`sw/applications/example_dot_product_hls`) is the same for all three.

How the three tools differ:

| | Vitis HLS | Bambu HLS | Dynamatic |
|---|---|---|---|
| Scheduling | static, pipelined (II) | static (FSM + datapath) | dynamic: dataflow circuit of valid/ready channels |
| Kernel | C++ + `#pragma HLS` | C++ + Bambu's `#pragma HLS interface` | C, no pragmas, fixed-size arrays, result returned |
| Emitted interface | AXI4-Lite CTRL + AXI4 masters | start/done + plain ports + AXI4 masters | handshake channels + BRAM-like array ports (1-cycle read, no stall) |
| CTRL registers | generated by the tool | regtool (`common/dot_product`) | regtool (`common/dot_product`) |
| Operand fetch | core's AXI masters (bursts) | core's AXI masters (single beat) | adapter copies a/b into local RAMs first (max 1024 elements) |
| HDL | Verilog | Verilog | Verilog (`write-hdl --hdl verilog`; default VHDL) |
| Host needs | licensed Vivado + Vitis HLS | Docker | Docker |
| Docker image | -- | ~5 GB, downloads the release AppImage | ~4.1 GB, built from source (~12 min, one-off) |

Full guide: [`docs/source/FPGA/HLS_DotProduct_Example.md`](../../../docs/source/FPGA/HLS_DotProduct_Example.md).
