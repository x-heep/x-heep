My X-HEEP Guide

1️⃣ Connect to the ESL Server (11 or 13)

ssh -X lenges@eslsrv13.epfl.ch

2️⃣ Navigate to Project & Activate Environment

cd scrap/lenges/x-heep
conda activate core-v-mini-mcu

3️⃣ Build Hardware (see Docu for detailed building)

From /x-heep root:

make mcu-gen
# Specify RAM on chip with MEMORY_BANKS=X (up to 16, default 2)

4️⃣ Build Software

Still in /x-heep root, choose the right project and linker:

make app PROJECT=example_w25q128jw_write LINKER=flash_load
# Or use LINKER=on_chip / flash_exec as needed

5️⃣ Run Simulation (QuestaSim)

make questasim-build-opt
cd ./build/openhwgroup.org_systems_core-v-mini-mcu_1.0.1/sim-modelsim/
make run-gui RUN_OPT=1 PLUSARGS="c firmware=../../../sw/build/main.hex boot_sel=1 execute_from_flash=0" &
run -all (restart for change in application)
cat uart0.log
# boot_sel=1 for flash_load/flash_exec linker, on_chip=0
# PASS_FWAIT=1 to bypass the flash wait states in case of simulation
# Put signals in waves before otherwise won't be visible
restart -f
run -a

5️⃣ Run Simulation (Verilator)


make verilator-build
make verilator-run SIM_ARGS="+boot_sel=1"

# If verilator-sim doesn't work, fix the warnings first in .vlt file if issue comes from Verilator and not written HW.

cd ./build/openhwgroup.org_systems_core-v-mini-mcu_0/sim-verilator
./Vtestharness +firmware=../../../sw/build/main.hex
cat uart0.log

6️⃣GTKwave

cd ./build/openhwgroup.org_systems_core-v-mini-mcu_0.3.0/sim-verilator
gtkwave waveform.fst &

To inspect waveforms after simulation, open the generated .vcd or .fst file in GTKwave.

Signals of interest are located under the following hierarchy:

testharness → x_heep_system_i → core_v_mini_mcu_i → peripheral_subsystem_i → w25q128jw_controller_i
testharness → x_heep_system_i → core_v_mini_mcu_i → ao_peripheral_subsystem-i → spi_subsystem_i → ot_spi_i

To save your current signal setup for later use:

  • Select or highlight the desired signals in the GTKwave interface.
  • Press G to generate a group (first highlight in Signals column)
  • File → Write Save File to generate a .sav file.
